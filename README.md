# GPT Business 운영대장

여러 ChatGPT Business 워크스페이스의 좌석, 상시 멤버, 기간제 멤버, 강의 일정을 관리하는 정적 웹앱입니다. 실제 ChatGPT 로그인·초대·삭제는 수행하지 않으며 운영 상태만 기록합니다.

## GitHub Pages 배포

1. 이 폴더의 전체 파일을 GitHub 저장소 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 `GitHub Actions`로 선택합니다.
3. `main` 브랜치에 push하면 `.github/workflows/deploy-pages.yml`이 사이트를 자동 배포합니다.

별도의 `npm install`이나 빌드 명령은 필요 없습니다. `index.html`을 직접 열어도 로컬 데모로 동작합니다.

## Google Sheets 연결

1. 빈 Google Spreadsheet를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs`의 내용을 붙여 넣습니다.
3. Apps Script 편집기에서 `setup` 함수를 한 번 실행하고 권한을 승인합니다.
4. **배포 → 새 배포 → 웹 앱**을 선택합니다.
5. 실행 사용자는 본인, 접근 권한은 운영 환경에 맞게 선택한 뒤 배포합니다.
6. 생성된 `/exec` URL을 웹앱의 **연결 설정** 화면에 입력합니다.

`apps-script/Code.gs`를 업데이트한 경우에는 Apps Script의 기존 배포에서
**새 버전**을 선택해 다시 배포해야 변경 내용이 웹앱에 반영됩니다. 강의
일시는 시간대 변환 대상이 아닌 입력값 그대로의 텍스트로 저장됩니다.

연결 전에는 브라우저 `localStorage`에만 저장됩니다. 연결 후에도 네트워크 오류에 대비해 마지막 데이터가 브라우저에 남습니다.

## 데이터 시트

`setup()` 실행 시 다음 시트가 생성됩니다.

- `roots`: 워크스페이스 소유 계정, 결제일, 만료일, 좌석 수
- `children`: 워크스페이스의 상시 멤버
- `guests`: 임시 초대 기간제 멤버와 제거 처리일
- `courses`: 강의 일정, 필요 좌석, 멤버 종류(`memberMode`), 배정 결과
- `settings`: 소유자 좌석 포함 여부

`courses` 시트에 `memberMode` 열이 추가되었으므로, 기존 시트를 쓰고 있다면
`Code.gs`를 새 버전으로 다시 배포한 뒤 웹앱에서 한 번 저장하면 열이 채워집니다.

## 강의별 자동 배정

강의를 만들 때 **사용할 멤버 종류**를 상시 또는 기간제로 고르면, 대시보드의
`강의별 자동 배정 계획` 카드가 무엇을 쓰면 되는지 계산해 보여줍니다.

- **상시 멤버**: 실제로 쓸 계정 이메일을 강의별로 뽑아 줍니다. 상시 계정은 이미
  좌석을 점유하고 있으므로 제약은 좌석이 아니라 계정 충돌입니다. 시간이 겹치는
  다른 강의에 배정된 계정은 자동으로 제외됩니다. 워크스페이스 소유자 계정도
  배정 대상에 포함되며, 전용 상시 계정을 모두 쓴 뒤 마지막에 사용됩니다.
  `연결 설정`의 **Root 소유자 1석 포함**을 끄면 소유자는 좌석이 없는 것으로 보고
  배정 대상에서도 빠집니다.
- **기간제 멤버**: 강의 날짜 기준으로 빈 좌석이 남아 있는 워크스페이스와 초대할
  인원 수를 배정합니다. 그 날짜에 유효한 다른 기간제 초대는 좌석에서 미리 빠집니다.

배정 순서는 강의 시작 시각 순이며, 먼저 잡힌 강의가 좌석과 계정을 먼저 가져갑니다.
한 워크스페이스로 충당되면 그쪽에 몰아주고, 어느 곳도 혼자 감당하지 못할 때만
여유가 많은 순서로 나눠 배정합니다. 그래도 모자라면 부족한 수량을 표시하며,
자동으로 다른 종류의 멤버로 대체하지는 않습니다.

강의 폼의 **우선 배정 워크스페이스**를 지정하면 그 워크스페이스가 감당할 수 있는
한 먼저 사용합니다. 비워 두면 전적으로 자동 배정에 맡깁니다.

## 수정과 삭제

워크스페이스, 상시 멤버, 기간제 멤버, 강의 일정 모두 편집 창에서 수정하고 삭제할 수
있습니다. 강의는 대시보드 배정 카드나 캘린더의 강의 칩을 눌러 엽니다. 워크스페이스를
삭제하면 그 워크스페이스의 상시·기간제 멤버 기록도 함께 지워지며, 삭제 전에 몇 건이
사라지는지 확인 창에 표시됩니다.

## 멤버 CSV 일괄 등록

워크스페이스 또는 기간제 멤버 화면에서 **CSV 일괄 등록**을 누르면 상시·기간제 멤버를 한 번에 추가할 수 있습니다. 화면의 **예시 CSV 다운로드**를 이용하거나 `member-import-sample.csv`를 편집하세요.

- 공통 필수 열: `member_type`, `email`, `workspace_email`
- `member_type`: `상시` 또는 `기간제`
- `workspace_email`: 등록할 워크스페이스의 소유자 이메일
- 기간제 멤버 필수 열: `start`, `end` (`YYYY-MM-DD`)
- `name`이 비어 있으면 이메일의 `@` 앞부분을 멤버명으로 사용
- 오류가 있는 행이 하나라도 있으면 전체 등록을 중단하고 행 번호와 원인을 표시

## 보안 참고

정적 GitHub Pages에는 서버 비밀값을 안전하게 숨길 수 없습니다. `config.js`에 비밀키, 비밀번호, 개인 데이터 또는 서비스 계정 키를 넣지 마세요.

`config.js`의 `appsScriptUrl`은 기본 데이터 원본 주소이며 사이트에 그대로 공개됩니다. Apps Script 배포 접근 권한이 “모든 사용자”이면 **이 URL을 아는 사람은 누구나 명단을 읽고 덮어쓸 수 있습니다.** 저장소가 공개라면 주소도 함께 공개된다는 뜻이므로, 운영 데이터에 실명·이메일이 들어간다면 다음 중 하나를 택하세요.

- `config.js`를 비워 두고 운영자가 **연결 설정** 화면에서 직접 주소를 입력해 쓰기 (주소는 각자 브라우저에만 저장됨)
- 저장소를 비공개로 전환하고 Pages를 조직 전용으로 제한
- Apps Script 앞에 별도의 인증 프록시를 두기

**연결 우선순위**는 `연결 설정`에 저장된 값 → `config.js` 기본값 순입니다. `연결 해제`를 누르면 이 브라우저에서는 기본값도 쓰지 않으며, 주소 칸을 비운 채 `연결 저장`을 누르면 기본값으로 돌아갑니다.
