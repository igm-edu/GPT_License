# GPT Business 계정 일정

날짜별로 어떤 계정을 쓸지 그대로 적어 두는 정적 웹앱입니다. 엑셀에서 표를 복사해 붙여넣으면
날짜별로 나눠 정리하고, 지난 날짜는 자동으로 감춥니다. 실제 ChatGPT 로그인·초대·삭제는
수행하지 않으며 운영 기록만 남깁니다.

## 쓰는 방법

대시보드가 곧 시트입니다. **칸을 눌러 바로 고치고**, 행 오른쪽 끝의 `×`로 지웁니다.
삭제한 직후에는 화면 아래에 **되돌리기**가 잠깐 뜹니다.

| 조작 | 동작 |
|---|---|
| `Enter` · `↑` `↓` | 같은 열에서 위아래 칸으로 이동 |
| `Tab` | 오른쪽 칸으로 이동 |
| 칸에서 `Ctrl+V` | 엑셀 표를 그 칸부터 아래·오른쪽으로 채움 |
| 맨 아래 빈 줄에 입력 | 새 행이 생기고 빈 줄이 다시 내려감 |

고친 내용은 곧바로 브라우저에 저장되고, 잠시 뒤 Google Sheets로 한 번에 보냅니다.
칸마다 저장 요청이 나가지 않도록 모았다가 보내는 방식입니다.

## 날짜가 여러 열로 나뉜 표

오른쪽 위 **엑셀 붙여넣기**는 아래처럼 날짜가 가로로 펼쳐진 표를 넣을 때 씁니다.

```
No   과정명        이름     09월 21일(월)            과정명      09월 22일(화)
1    태림페이퍼    김동주   coramdeo0916@...         현대해상    wodnr123dla@...
2    태림페이퍼    김윤정   kyja_a@...
```

날짜 열에 계정이 들어 있고, 그 왼쪽 열들이 과정명·이름으로 해석됩니다.
`과정명` `이름` `메모`가 들어간 머리글을 찾아 짝지으므로 열 순서는 달라도 됩니다.
머리글에 날짜가 없으면 창에서 날짜를 직접 고르면 됩니다.

인식하는 날짜 표기는 `09월 21일(월)`, `2026-09-21`, `2026.09.21`, `9/21`, `09-21` 등입니다.
연도가 없으면 올해로 보되, 반년 이상 지난 날짜면 내년으로 해석합니다.

**처리 방식**에서 `해당 날짜를 이 내용으로 교체`(기본)를 쓰면 엑셀을 고쳐 다시 붙여넣어도
중복이 생기지 않습니다.

## 지난 날짜

오늘보다 이전 날짜는 목록에서 자동으로 빠집니다. 목록 위의 **지난 날짜 보기**를 켜면 흐린
행으로 함께 보이고, 연결 설정 화면의 **지난 날짜 모두 삭제**로 한 번에 정리할 수 있습니다.

## 복사해 가기

목록 위의 **복사** 버튼은 화면에 보이는 행을 그대로 가져갑니다. 검색이나 `지난 날짜 보기`로
걸러 둔 상태 그대로 복사되므로, 필요한 부분만 골라 옮길 수 있습니다.
`날짜 · 과정명 · 이름 · 계정 · 메모` 순서의 탭 구분 표라서 엑셀에 붙여넣으면 셀이 나뉩니다.

## GitHub Pages 배포

이 폴더의 파일을 저장소 `main` 브랜치에 올리면 됩니다. 빌드나 `npm install`은 필요 없고,
`index.html`을 직접 열어도 로컬에서 동작합니다.

## Google Sheets 연결

1. 빈 Google Spreadsheet를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs`의 내용을 붙여 넣습니다.
3. **배포 → 새 배포 → 웹 앱**으로 배포하고, 생성된 `/exec` URL을 **연결 설정** 화면에 입력합니다.

`Code.gs`를 고친 뒤에는 기존 배포에서 **새 버전**을 선택해 다시 배포해야 반영됩니다.
연결 전에는 브라우저 `localStorage`에만 저장되고, 연결 후에도 네트워크 오류에 대비해
마지막 데이터가 브라우저에 남습니다.

### 데이터 시트

계정 일정은 `slots` 시트에 저장됩니다.

| 열 | 내용 |
|---|---|
| `id` | 행 식별자 |
| `date` | `YYYY-MM-DD` (텍스트 서식으로 고정) |
| `course` | 과정명 |
| `name` | 이름 |
| `account` | 계정 이메일 |
| `memo` | 메모 |

예전 화면에서 쓰던 `roots`, `children`, `guests`, `courses` 시트는 **지우지 않고 그대로
보존**합니다. 앱이 읽어서 그대로 다시 써 주므로 내용이 사라지지 않습니다.

## 보안 참고

정적 GitHub Pages에는 서버 비밀값을 숨길 수 없습니다. `config.js`의 `appsScriptUrl`은
사이트에 그대로 공개되며, Apps Script 배포 접근 권한이 “모든 사용자”이면 **URL을 아는 사람은
누구나 명단을 읽고 덮어쓸 수 있습니다.** 실명·이메일이 들어간다면 저장소를 비공개로 두거나,
`config.js`를 비워 두고 운영자가 **연결 설정** 화면에서 직접 주소를 입력해 쓰는 편이 안전합니다.

연결 우선순위는 `연결 설정`에 저장된 값 → `config.js` 기본값 순입니다. `연결 해제`를 누르면
이 브라우저에서는 기본값도 쓰지 않으며, 주소 칸을 비운 채 `연결 저장`을 누르면 기본값으로
돌아갑니다.
